# tst-firmware-release

Factory images of the JetHome test-system firmware, one release per
firmware version. Each release holds `<name>-factory.bin` per firmware
(flash at offset 0x0) and `SHA256SUMS`. `<name>` is the board and the
firmware type, for example `jxd-r6-e1eth-selftest` or
`jxd-r6-e1eth-hello`.
